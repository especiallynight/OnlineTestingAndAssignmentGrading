## Риски

- Малое покрытие тестами — тесты пишутся вместе с каждой функцией, минимум 3 теста на сервис с бизнес-логикой.
- Локальные сбои — коммит и push на каждое законченное действие.
- Проблемы с настройкой Docker Compose — проверка запуска проекта и тестов после каждого значимого этапа.
- Некорректная работа с базой данных — миграции EF Core, тестовые данные и резервные копии перед изменениями схемы.
- Обнаружатся дополнительные требования или изменится объём проекта — обновление журнала изменений плана.
